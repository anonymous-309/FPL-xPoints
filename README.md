# xPoints cho FPL

Dự đoán điểm Fantasy Premier League của từng cầu thủ trong các vòng tới. GitHub Actions tự chạy lúc 10:17 và 22:17 giờ Việt Nam mỗi ngày, thêm mỗi 2 giờ vào thứ Sáu và thứ Bảy, rồi cập nhật trang web của repo.

Muốn chạy ngay: vào tab **Actions**, chọn **Cap nhat xPoints**, bấm **Run workflow**.

Trang `Độ chính xác` là kết quả backtest trên mùa 2025/26. Không liên kết với Premier League.
