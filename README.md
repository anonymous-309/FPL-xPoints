# xPoints cho FPL

Dự đoán điểm Fantasy Premier League của từng cầu thủ trong các vòng tới. GitHub Actions tự chạy lúc 8:00 và 17:00 giờ Việt Nam mỗi ngày, thêm mỗi 2 giờ trong 24 giờ trước deadline, rồi cập nhật trang web của repo.

Muốn chạy ngay: vào tab **Actions**, chọn **Cap nhat xPoints**, bấm **Run workflow**.

Trang `Độ chính xác` là kết quả backtest trên mùa 2025/26. Không liên kết với Premier League.
