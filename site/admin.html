Saving writes admin_minutes.json to the GitHub repo, so this browser needs a GitHub token once: on GitHub, Settings → Developer settings → Fine-grained tokens → Generate new token, repository access Only select repositories: FPL-xPoints, permission Contents: Read and write. The token is kept only in this browser.

Admin min replaces a player's usual minutes (the 5-4-3-2-1 formula) for every upcoming gameweek, for everyone who uses the site, including xPoints and the Planner. Injuries, bans and doubtful flags still apply on top. Clear a box to go back to the formula. After you save, the site rebuilds with the new minutes in about 10 minutes.
